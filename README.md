# ES Journey · เว็บรายวิชาวิทยาศาสตร์โลกและอวกาศ (ว30114) ภาคเรียนที่ 2/2569

เว็บรวมใบงาน สื่อการสอน เค้าโครง 20 สัปดาห์ และผลการส่งงานรายห้อง/รายคน ธีมภารกิจอวกาศ
ดูในเครื่อง: ดับเบิลคลิก `index.html` (ไม่ต้องมีเซิร์ฟเวอร์)

## ใครแก้อะไร ตรงไหน

| อยากเปลี่ยน | แก้ไฟล์ | หมายเหตุ |
|---|---|---|
| ใบงาน สไลด์ สถานการณ์จำลอง ลิงก์กิจกรรมของสัปดาห์ | `weeks/wNN/` + `weeks/wNN/items.js` | วางไฟล์ในโฟลเดอร์สัปดาห์ แล้วเพิ่ม 1 บรรทัดใน `items.js` ของสัปดาห์นั้น |
| ประกาศหน้าแรก ลิงก์กลาง (Apps Script สอบกลางภาค) | `data/site.js` | |
| เค้าโครง 20 สัปดาห์ งาน คะแนนต่องาน | `data/course.js` | แก้เมื่อรายวิชาเปลี่ยนเท่านั้น |
| ผลการส่งงาน คะแนน | `data/scores.js` | **ห้ามแก้ด้วยมือ** Claude สร้างจาก master ใน `60_คะแนน` |
| หน้าตาเว็บ | `assets/app.js`, `assets/site.css` | ให้ Claude แก้ |

## ตัวอย่างบรรทัดใน items.js

```js
ESJ.week(4, [
  { type: "slides",    title: "สไลด์ สัปดาห์ที่ 4 กาแล็กซีทางช้างเผือก", file: "w04-slides.pdf" },
  { type: "worksheet", code: "E3", title: "ใบงาน E3 กาแล็กซีทางช้างเผือก", file: "e3-worksheet.pdf", note: "ส่งท้ายคาบคู่" },
  { type: "sim",       title: "สถานการณ์จำลอง มองทางช้างเผือกจากโลก", file: "e3-sim-milkyway.html" },
  { type: "video",     title: "วีดิทัศน์ ...", url: "https://www.youtube.com/watch?v=..." },
]);
```

type: `slides` สไลด์ · `worksheet` ใบงาน · `sim` สถานการณ์จำลอง HTML · `activity` กิจกรรมออนไลน์/Apps Script · `video` · `link` · `doc`
ช่องเสริม: `code` รหัสงาน, `note` คำอธิบายสั้น, `qr` รูป QR ในโฟลเดอร์เดียวกัน

## กติกา
- ชื่อไฟล์ใน `weeks/` ใช้ภาษาอังกฤษ ตัวเลข `-` `_` ไม่มีเว้นวรรค เช่น `e3-worksheet.pdf`
- **ห้ามวาง** เฉลย ข้อสอบ ไฟล์ Word/Excel/CSV รายชื่อ หรือเลขประจำตัวนักเรียนใน repo นี้
- เว็บแสดงเลขที่ + ชื่อ-นามสกุล และสถานะส่งงาน ไม่แสดงเลขประจำตัวและรูปนักเรียน ไม่จัดอันดับ มี `noindex`
- ก่อนให้ครู Push ให้รัน `python "../_เครื่องมือ/check_site.py"` ต้องขึ้นคำว่า "ผ่าน"
