# ES Journey · เว็บรายวิชาวิทยาศาสตร์โลกและอวกาศ (ว30114) ภาคเรียนที่ 2/2569

เว็บรวมใบงาน สื่อการสอน เค้าโครง 20 สัปดาห์ และผลการส่งงานรายห้อง/รายคน ธีมภารกิจอวกาศ
ดูในเครื่อง: ดับเบิลคลิก `index.html` (ไม่ต้องมีเซิร์ฟเวอร์)

## ใครแก้อะไร ตรงไหน

## ตัวอย่างบรรทัดใน items.js

```js
ESJ.week(4, [
  { type: "slides",    title: "สไลด์ สัปดาห์ที่ 4 กาแล็กซีทางช้างเผือก", file: "w04-slides.pdf" },
  { type: "worksheet", code: "E3", title: "ใบงาน E3 กาแล็กซีทางช้างเผือก", file: "e3-worksheet.pdf", note: "ส่งท้ายคาบคู่" },
  { type: "sim",       title: "สถานการณ์จำลอง มองทางช้างเผือกจากโลก", file: "e3-sim-milkyway.html" },
  { type: "video",     title: "วีดิทัศน์ ...", url: "https://www.youtube.com/watch?v=..." },
]);
```

type: `slides` สไลด์ · `worksheet` ใบงาน · `sim` สถานการณ์จำลอง HTML · `activity` กิจกรรมออนไลน์/Apps Script · `video` · `link` · `doc` · `key` เฉลยใบงาน (ขึ้นพร้อมทุกครั้งที่อัปเดตเว็บถึงสัปดาห์นั้น · ครูสั่ง 17 พ.ย. 2569)
ช่องเสริม: `code` รหัสงาน, `note` คำอธิบายสั้น, `qr` รูป QR ในโฟลเดอร์เดียวกัน

## กติกา
- ชื่อไฟล์ใน `weeks/` ใช้ภาษาอังกฤษ ตัวเลข `-` `_` ไม่มีเว้นวรรค เช่น `e3-worksheet.pdf`
- **เฉลยใบงาน:** ทุกครั้งที่อัปเดตเว็บให้ถึงสัปดาห์ใหม่ ให้ขึ้นเฉลยใบงานของทุกสัปดาห์จนถึงสัปดาห์นั้นไปด้วยเลย ไม่ต้องรอถาม (ครูสั่ง 17 พ.ย. 2569 แทนกติกา 2 พ.ย. ที่ให้รอจบสัปดาห์) ตั้งชื่อ `xx-answer-key.pdf` type `key` ใช้ไฟล์เฉลยฉบับล่าสุดที่ตรงกับ Drive `02_เฉลยและเกณฑ์/ES`
- **ห้ามวาง** ข้อสอบ เฉลยข้อสอบ ไฟล์ Word/Excel/CSV รายชื่อ หรือเลขประจำตัวนักเรียนใน repo นี้
- เว็บแสดงเลขที่ + ชื่อ-นามสกุล และสถานะส่งงาน ไม่แสดงเลขประจำตัวและรูปนักเรียน ไม่จัดอันดับ มี `noindex`
- ร้อยละรายคนและพลังทีม = งานที่ส่งแล้ว / งานที่ถึงกำหนด นับรวม 00 ลงทะเบียน งานไม่มีคะแนน (`checks` เช่น ES00) และงานสัปดาห์นี้ · สถานะ `ค้าง n` = งานสัปดาห์ก่อนที่ยังไม่ส่ง · `กำลังทำ` = งานสัปดาห์นี้ยังไม่ส่ง · ป้ายเสี่ยงติด ร คิดจากงานมีคะแนนเท่านั้น (ครูแจ้ง 4 พ.ย. 2569)
- แต่ละห้องเรียนเร็วช้าต่างกัน (17 พ.ย. 2569): งานที่ห้องนั้นยังไม่มีผลตรวจเลย (ครูยังไม่สแกนส่งตรวจ) ไม่นับเป็น `ค้าง` และไม่นับในร้อยละ หน้าห้องบอกว่า "ยังไม่มีผลตรวจของห้องนี้" · งานที่ห้องทำล่วงหน้า (สัปดาห์หลัง `asOfWeek`) ที่ยังไม่ส่งขึ้น `กำลังทำ` · "ภารกิจล่าสุด" ของแต่ละทีม = สัปดาห์ตามปฏิทิน หรือสัปดาห์ของงานล่าสุดที่ห้องนั้นมีผลตรวจ (เลือกที่ไกลกว่า) · เปลี่ยนสัปดาห์ให้แก้ `asOfWeek` ใน `data/scores.js` ช่องเดียว
- **ใบงานสแกนรายคน (ครูสั่ง 21 พ.ย. 2569 เลือกแบบ "เปิดได้ทุกคน"):** `data/worksheets.js` เก็บแค่รหัสงาน + file ID ของไฟล์สแกนใน Drive (ไม่มีเลขประจำตัว ไม่มีไฟล์สแกนใน repo) ไฟล์ใน Drive ตั้งแชร์ทีละไฟล์เป็น "ทุกคนที่มีลิงก์ ดูได้" **ห้ามแชร์ทั้งโฟลเดอร์** · ขึ้นเฉพาะไฟล์ที่เว็บนับว่าส่งแล้ว ไม่ใช่ไฟล์ที่ลิงก์กับนักเรียนหลายคน และเหตุผลในชีตไม่บอกว่าปนงานคนอื่น/จำนวนหน้าไม่ตรง (ไฟล์ที่กันไว้ครูตรวจแล้วใส่ใน `allow.json` ได้) · อัปเดต: ดึง `ผลการตรวจ!A1:Y` → รัน `build_worksheet_links.py --mode open` → แชร์ไฟล์ใน `need_share` ทีละไฟล์ แล้วเพิ่มใน `shared.json` (เครื่องมืออยู่ project files `es-worksheet-links/`) · โค้ดยังรองรับ `--mode gate` (เข้ารหัสลิงก์ด้วยเลขประจำตัว 5 หลัก) ถ้าครูเปลี่ยนใจ
- ก่อนให้ครู Push ให้รัน `python "../_เครื่องมือ/check_site.py"` ต้องขึ้นคำว่า "ผ่าน"
